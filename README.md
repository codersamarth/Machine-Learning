# ML Playground — INSEAD Machine Learning & Optimization

An interactive, beginner-first learning website focused on understanding machine learning and reading Python code. Static HTML/CSS/JavaScript: no backend, API keys, or build required.

## Deploy on Vercel
Import `codersamarth/Machine-Learning` at [vercel.com/new](https://vercel.com/new), choose **Other** as framework, leave build command empty, use `.` as output directory, and deploy. The root `index.html` is the site entry point. `vercel.json` supplies static routing.

## Run locally
`python -m http.server 8000`, then visit http://localhost:8000.

## Course design
Lectures 1–3 are covered in the learning labs; Lectures 4–15 remain syllabus roadmap entries until source materials are added. Original course materials are not redistributed. User notes and quiz progress remain in browser localStorage.

## Regression learning outcomes
Start with zero coding background, learn the meaning of data, features, labels, scatterplots, lines, slopes, intercepts, residuals, least squares, regression metrics, model evaluation, polynomial regression, overfitting, leakage, preprocessing and interpretation of real scikit-learn notebook code. Work through line-by-line code translation, shape tracing and code prediction exercises.

*Educational study aid; not an official INSEAD course website.*
